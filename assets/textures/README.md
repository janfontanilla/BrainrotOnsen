# Map textures

Seamless toy-brick tiles generated by `tools/make_textures.py` (run it again to regenerate or tweak the colours). They give the map the studded look of Capybara Onsen (see `reference/`).

| File | Used on | Studs per tile |
| --- | --- | --- |
| `grass.png` | plot floor, ground | 8 |
| `water.png` | baths, rivers, channel, pool | 8 |
| `stone.png` | bath bases and rims, dividers, pool rim | 8 |
| `pegboard.png` | the tall wall | 8 |
| `cliff.png` | the cliffs | 16 |
| `arrow.png` | floor arrows toward pads (not placed yet) | 6 |
| `planks.png` | slides, bridge, stall wood | 8 |
| `onsen.png` | hot-spring mark for noren banners (white on transparent; a decal) | - |
| `ui_studs.png` | HUD button stud overlay (tiled, `client/Style`) | - |
| `aura_icon.png` | HUD Aura gem icon (`client/Style`) | - |

All tiles share one style (same 2-stud grid, bevel and inset square, only the colour differs); the water has stream streaks. **Status (2026-09-29): all are uploaded** (by Claude through the Studio MCP `upload_image`, from a local `python -m http.server`). IDs are in `src/shared/Config/Textures.luau`. The five tiles used as MaterialVariants (grass, stone, pegboard, cliff, planks) are also declared in `default.project.json` under `MaterialService`: when an ID changes, change it in both places and restart `rojo serve`. The tiles were redrawn in the unified style and re-uploaded on 2026-09-29 (new IDs in both places). The two HUD images' IDs live in `src/client/Style.luau`.

## Uploading by hand (if the Studio MCP is not available)

Option A: Studio
1. In Studio open View > Asset Manager.
2. Click Bulk Import and select the six PNGs in this folder.
3. Wait for them to finish (they are checked by Roblox; usually a few minutes).
4. In Asset Manager, right-click each image > Copy ID.

Option B: Creator Dashboard
1. Go to create.roblox.com > Creations > Assets (or "Upload") > Images (Decals).
2. Upload each PNG. Open it and copy the asset ID from the URL.

Then paste each ID into `src/shared/Config/Textures.luau` (and, for a tile variant, into `default.project.json`). `server/Skin.luau` applies them on the next server start. If a texture looks wrong (too big or small), change its `studsPerTile`.

Use the Image asset ID. If Roblox gives you a "Decal" ID that does not display, use the Image ID instead (in Asset Manager the copied ID is usually the right one).
